# FMI Intellectual Provenance Standard

Version 1.0. This standard records evidence-backed intellectual lineage; it does not create rights in ideas, methods, independently created work, or generic patterns.

## Required project record

Each applicable active repository should contain `PROVENANCE.md` with these sections:

1. **Project identity** — name, canonical repository, public originating identity, verified repository/history links, and development status.
2. **Intellectual contribution** — narrowly describe documented contribution; distinguish implementation, specification, hypothesis, and established methods.
3. **Prior art and influences** — only sources actually documented or otherwise verified. State limits on novelty claims.
4. **Implementation relationships** — evidence-backed upstream, downstream, and FMI relationships; label unresolved relationships as such.
5. **Attribution** — copied-expression obligations separate from recommended methodological citation and voluntary acknowledgements.
6. **Licensing** — existing licence(s), documentation terms, and any separately approved additional terms. State what the licence does not control.
7. **Version history** — verified repository, release, and publication records; do not convert repository creation dates into publication claims.
8. **Evidence and limitations** — sources, unknowns, and unresolved authority/ownership questions.

## Status vocabulary

Use only these labels where supported: `IMPLEMENTED`, `SPECIFIED`, `HYPOTHESISED`, `EXPERIMENTAL`, `HISTORICAL`, and `SUPERSEDED`.

## Attribution boundary

Preserve notices and licences when copying protected expression. Cite a documented method as scholarly/professional practice when useful, but do not describe that courtesy as a licence obligation. An independently implemented method is not automatically governed by a software licence merely because it resembles an FMI approach.

## Archived repositories

Archived repositories are indexed in the central registry by default. Their historical contents are not retrofitted absent an explicit, evidence-reviewed decision.
